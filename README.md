## 4. خطوات التشغيل (How to Run)
1. افتح برنامج **SQL Server Management Studio (SSMS)** ونفّذ ملف `database/schema_and_data.sql` لإنشاء قاعدة البيانات والجداول والبيانات التجريبية.
2. افتح ملف الحل `.sln` داخل مجلد `src/` باستخدام **Visual Studio**.
3. عدّل اسم السيرفر في جملة الاتصال (`Connection String`) ليطابق جهازك (مثل `.\SQLEXPRESS`).
4. شغّل البرنامج (`F5`) وجرّب عمليات الإضافة والعرض والتعديل والحذف.
